## 📁 ファイル構成
- `*_narration.txt`: 朗読・音声合成（TTS）専用のクリーンテキスト（タイトル＋小説本文のみ）
- `*_full.txt`: 小説本文＋技術解説＋引用文献＋次回予告を含む完全テキスト
- `*.md`: オリジナルMarkdown原稿
- `archive_index.json`: 作品メタデータ一覧（JSON）
